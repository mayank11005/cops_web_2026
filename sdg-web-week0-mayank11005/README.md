## 🧠 Foundational Web Technologies

To complete this assignment, you need a basic understanding of the core frontend technologies:

### 1. HTML (HyperText Markup Language)
HTML is the skeleton of every web page. It defines the basic structure and hierarchy of content using elements represented by tags (e.g., `<h1>`, `<p>`, `<img>`, `<div>`). Think of it as the structure of a building—the walls, floors, and rooms.

### 2. CSS (Cascading Style Sheets)
CSS is the paint, styling, and interior decoration of your website. It specifies the visual appearance of HTML elements—controlling colors, fonts, backgrounds, padding, margins, and complex layouts. It is what turns a plain document into a beautiful visual interface.

## 🎯 The Challenge: Clipboard Landing Page

Your main task is to build out a pixel-perfect landing page for a product called "Clipboard" and make it look as identical to the given designs as possible. 

### 🗂️ Where to Find Everything
*   **Mockups & Design Specifications:** Look inside the [`/design`](./design) folder. You will find:
    *   `desktop-design.jpg`: The target appearance for wide desktop screens.
    *   `mobile-design.jpg`: The target appearance for mobile phone screens.
    *   `active-states.jpg`: Shows how interactive elements (buttons, links) should change color/state when hovered over.
*   **Visual Assets:** All icons, logos, and background graphics are provided for you in the [`/images`](./images) folder.
*   **Boilerplate Code:** A minimal HTML file is provided for you in [`index.html`](./index.html). **Your job is to update this file with your own HTML markup and CSS styling.**

### ✨ Bonus Goal: Responsiveness 📱💻
**Extra points will be awarded for making your landing page fully responsive!** A responsive website dynamically adjusts its layout to fit gracefully across different screen sizes (from small mobile screens to large desktop monitors) rather than just breaking or looking cramped. 

### 🚀 Optional Tech: Tailwind CSS
While you can absolutely write plain (vanilla) CSS, you are welcome to use **Tailwind CSS** if you'd like to explore modern utility-first CSS workflows. It speeds up the styling process by allowing you to apply styles directly in your HTML via utility classes.

## 🛠️  Instructions

Since this is a **GitHub Classroom** assignment, you have automatically received your own **private fork** of this repository. Follow these steps to complete the work:

### Step 1: Clone Your Fork
Clone this repository to your local development machine using Git so that you can begin editing files locally.

### Step 2: Develop the Site
Modify the provided `index.html` file and build out the layout. 
*   *💡 Pro-Tip:* Open the file using the **VS Code Live Server extension** to see your changes rendered in real-time inside your browser every time you save!
*   *💡 Pro-Tip:* Practice writing **Semantic HTML**. Use specific tags like `<header>`, `<main>`, `<section>`, and `<footer>` to group your sections logically instead of relying solely on generic `<div>` containers.

### Step 3: Fill Out Student & Project Details
Before submitting, you must populate two administrative text files in the root directory:
1.  **`info.txt`**: Open this file and enter your personal details (Name, Roll No, Discord Username, etc.) in the provided slots.
2.  **`demo.txt`**: Record a brief video demonstration of your working website (showing desktop, mobile view, and button hover effects) and paste your shareable link in this file. (You can upload the video to YouTube or Google Drive).

### Step 4: Commit & Push
Save your progress, commit your final changes using Git, and push them back to your private GitHub repository before the deadline.
